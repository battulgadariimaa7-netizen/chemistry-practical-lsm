# Chemistry Practical & LSM

An interactive study site for Cambridge International AS & A Level Chemistry (9701) practical skills and laboratory safety management, in English and Mongolian. It works offline after the first visit.

**Open the site:** https://battulgadariimaa7-netizen.github.io/chemistry-practical-lsm/

Independent study tool, not an official Cambridge or publisher product. Always follow your teacher and your school's laboratory rules.

## Run it on your own computer

```
npm install
npm run dev
```

The site is served through GitHub Pages from the `gh-pages` branch, which holds the built files.
